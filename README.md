# Tower King

A platform jumping game built with Phaser.js where you need to survive as long as possible by jumping between platforms while avoiding falling into the water.

## How to Play

- Use LEFT and RIGHT arrow keys to move
- Use UP arrow key to jump
- Avoid falling into the water
- Stay alive as long as possible to get a high score
- Platforms will move faster as time progresses

## Development Setup

1. Clone this repository
2. Serve the files using a local web server (due to browser security restrictions)
3. Open index.html in your browser

## Assets Required

Place the following images in the `assets` directory:
- player.png (32x32 player sprite)
- platform.png (128x16 platform sprite)
- water.png (800x40 water sprite)
